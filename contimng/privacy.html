꿈꾸는콘티 개인정보처리방침

시행일: 2026년 11월 19일

1. 개요

꿈꾸는콘티("앱")는 찬양팀이 악보와 예배 콘티(곡 순서)를 관리하기 위한 앱입니다. 개발자는 사용자의 개인정보를 소중히 여기며, 이 개인정보처리방침은 앱이 어떤 정보를 다루고 어디에 저장하는지 설명합니다.

요약: 개발자는 사용자의 개인정보를 수집하지 않습니다. 앱에는 회원가입이나 로그인이 없고, 개발자가 운영하는 서버도 없습니다. 사용자가 입력한 데이터는 사용자의 기기에 저장되며, 사용자가 S3 동기화를 설정한 경우에만 사용자 본인의 Amazon S3 저장소로 전송됩니다.

2. 처리하는 정보

2.1 개발자가 수집하는 정보

개발자는 어떠한 개인정보도 수집하지 않습니다. 앱에는 다음이 포함되어 있지 않습니다. - 회원가입, 로그인, 계정 - 광고 SDK - 사용 통계·분석 도구 - 오류(크래시) 보고 도구 - 위치 정보, 연락처, 기기 식별자 수집

2.2 기기에만 저장되는 정보

사용자가 앱에 직접 입력하거나 등록한 다음 정보는 사용자 기기의 앱 전용 저장공간에 저장됩니다. - 악보 정보(번호, 제목, 첫 구절, Key 등)와 악보 이미지 - 콘티(날짜, 제목, 곡 순서), 템플릿 - 악보 위에 펜으로 작성한 메모 이미지 - 앱 설정(사용 가이드 확인 여부 등)

2.3 S3 연결 정보

S3 동기화를 사용하려면 사용자가 직접 다음 정보를 입력합니다. - S3 이름(사용자가 정한 별칭), Access Key, Secret Key, Region, Bucket 이름

이 정보는 사용자 기기의 앱 전용 저장공간에만 저장되며, 사용자가 지정한 S3에 접속할 때만 사용됩니다. 개발자에게 전송되지 않습니다.

권장 사항: Access Key는 앱에서 사용할 버킷에만 권한이 있는 키(최소 권한의 IAM 사용자 키)를 사용하시기 바랍니다.

3. 정보의 이용 목적

기기에 저장된 정보는 다음 기능을 위해서만 사용됩니다. - 악보·콘티·템플릿 등록, 조회, 수정 - 콘티 보기(악보 넘기기, 메모 표시) - 사용자가 설정한 S3 저장소와의 동기화 - 콘티 PDF 생성 및 공유

4. 정보의 전송 및 제3자 제공

개발자는 사용자의 정보를 제3자에게 제공하거나 판매하지 않습니다. 단, 사용자가 직접 실행하는 다음 기능에 한해 정보가 기기 밖으로 전송됩니다.

4.1 S3 동기화

사용자가 [지금 동기화]를 실행하면 악보·콘티·템플릿 데이터와 이미지가 사용자가 입력한 Amazon S3 버킷으로 암호화된 통신(HTTPS)을 통해 전송되고, 같은 버킷에서 데이터를 내려받습니다. 이 저장소는 사용자 본인(또는 사용자가 속한 단체)이 소유·관리하는 AWS 계정이며, 개발자는 접근할 수 없습니다. S3에 저장된 데이터의 처리에는 AWS 개인정보처리방침이 적용됩니다.

4.2 콘티 공유

사용자가 콘티 [공유]를 실행하면 콘티의 악보 이미지로 만든 PDF 파일(또는 이미지)이 사용자가 선택한 앱(카카오톡, 문자, Gmail 등)으로 전달됩니다. 전달된 이후의 처리는 해당 앱의 개인정보처리방침을 따릅니다.

공유 메뉴에 카카오톡·Gmail·문자 앱을 표시하기 위해 해당 앱이 기기에 설치되어 있는지만 확인하며, 설치된 앱 목록을 수집하거나 전송하지 않습니다.

4.3 법령에 따른 제공

개발자는 정보를 보관하지 않으므로 제공할 정보가 없습니다.

5. 앱 권한

권한 용도
인터넷 사용자가 설정한 S3 저장소와 동기화
사진 선택 악보 이미지를 등록할 때 시스템 사진 선택기를 통해 사용자가 고른 사진만 가져옵니다. 사진첩 전체에 접근하지 않습니다.

앱은 카메라, 위치, 연락처, 마이크 권한을 사용하지 않습니다. 콘티를 보는 동안 화면이 꺼지지 않게 하는 기능은 별도의 정보를 처리하지 않습니다.

6. 정보의 보관 및 삭제

  • 기기에 저장된 정보: 사용자가 앱에서 삭제하거나 앱을 삭제할 때까지 보관됩니다. 앱을 삭제하면 기기에 저장된 악보·콘티·메모와 S3 연결 정보가 모두 삭제됩니다.
  • S3 목록에서 S3를 삭제한 경우: 해당 S3로 받아둔 기기 내 데이터와 연결 정보가 삭제됩니다. S3에 저장된 원본은 삭제되지 않습니다.
  • S3에 저장된 정보: 사용자의 AWS 계정에 있으며, 사용자가 AWS에서 직접 관리·삭제할 수 있습니다.

7. 데이터 보안

  • S3와의 통신은 모두 HTTPS로 암호화됩니다.
  • 기기 내 정보는 다른 앱이 접근할 수 없는 앱 전용 저장공간에 저장됩니다.
  • 다만 기기 자체의 분실이나 잠금 해제 상태의 노출까지 앱이 막을 수는 없으므로, 기기 화면 잠금을 사용하시기 바랍니다.

8. 사용자의 권리

개발자는 사용자의 개인정보를 보관하지 않으므로, 열람·수정·삭제는 앱에서 직접 할 수 있습니다. - 악보·콘티·템플릿·메모: 앱에서 수정 또는 삭제 - S3 연결 정보: [동기화] 탭의 S3 목록에서 수정 또는 삭제 - 전체 삭제: 앱 삭제

그 밖의 문의는 아래 연락처로 보내주시기 바랍니다.

9. 아동의 개인정보

이 앱은 아동을 대상으로 하지 않으며, 아동을 포함한 누구의 개인정보도 수집하지 않습니다.

10. 저작물 이용 안내

사용자가 등록하는 악보 이미지의 저작권은 각 권리자에게 있습니다. 악보의 등록·공유는 사용자(또는 사용자가 속한 단체)가 보유한 이용 권한 범위 안에서 해 주시기 바랍니다.

11. 개인정보처리방침의 변경

이 개인정보처리방침이 변경되는 경우 시행일과 함께 이 페이지에 게시합니다. 앱이 정보를 처리하는 방식이 바뀌는 중요한 변경은 앱 업데이트 안내를 통해 알려드립니다.
